# Design brief：《AI 递归自我改进》综述汇报

参考：合稿-20260707电力人工智能自主科研引擎方案汇报.pptx（44 页，渲染图见 review/reference/）。
论文：arXiv:2607.07663v1，Chen, Wang, Qu，2026.07，Recursive Self-Improvement in AI。

## 用户要求 vs 参考的附带特征
- 用户明确要求：参考这份电力 PPT 制作；内容按论文的具体内容；中文汇报稿。
- 从参考继承的视觉语法：国家电网母版（logo + 标题下细横线 + 楼宇底图 + 页码）、"目录 CONTENTS" 章节过渡页、"章.节 标题 – 副标题" 编号、虚线导语框 + 红色关键词、青绿实心标签头、底部红色结论句、三栏/表格高密度、闭环/层级流程图。
- 不搬参考的业务内容（创世纪计划、电力科研平台、建设时间表等）；所有数字和论断来自论文。封面单位写论文作者与 arXiv 号，不虚构汇报单位。

## 母版（BASE = 参考 .pptx）
- 正文页用 layout「1_标题幻灯片」（参考 38 页在用）：logo 26,21,84×83；横线 y=122；页码框 1518,862,80×38；左下楼宇底图（淡）。内容区 x 20–1580、y 136–855，页码框不放内容。
- 封面、结束页用「空白」（ref-01, ref-44）：青绿横带 y 206–652、细线 y 233/620、左上大 logo 15,33,409×139。封面标题白字两行置于横带内；底部两行深色加粗（作者/日期）。

- 导语框（所有正文页，ref-03…ref-43 一致）：x=20, y=142, w=1560，008A88 细虚线、无填充；20 pt，首行缩进两字；关键词 C00000 加粗；2–3 行。

## 色彩角色（参考色 → 本稿色）
论文是 AI 综述，无与电力强绑定的色相要求；母版 logo、横带、底图均为青绿，换色相会与母版冲突，因此色相保持不变，按角色映射：
- navy（标题、深色强调）：064E41 → 064E41
- blue（主青绿：标签头、描边、箭头、表头）：008380 → 008380
- gold（深青：块箭头、次级标签）：0E6767 → 0E6767
- rose（红色关键词、失败模式）：C00000 → C00000；darkRose：9E1B1B
- pale（浅青小框）：EFF7F7/D5ECEB → EFF7F7；zone（面板浅底）：ECF6F6 → ECF6F6
- paleRose（失败模式底）：FBE9E9；line（细线）：98D1CC；text：1F2D2D；grey（说明文字蓝灰）：57678F；chipGrey（目录灰条）：E6E6E6；sky：0070C0
- 深浅层次与参考一致：标签头/表头/封面横带为深色，面板底/小框为浅色，红色只用于关键词。
- 字体：微软雅黑（参考 1033 次）。
